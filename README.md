# Endless road-crossing game on DTEK-V

Mini project, group 67: **Adam Wahren** and **Neo Carlberg**.

A 2D endless road-crossing game written in C for the DTEK-V (RISC-V) board. A frog crosses
an endless world of lanes with moving vehicles. Graphics go to VGA, the score is shown on the
7-segment displays, and the player is controlled with the board's button and switches.
